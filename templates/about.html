О проекте TimeLearn

TimeLearn — учебный проект для тех, кто хочет одновременно освоить Python и научиться управлять своим временем.

Что внутри?

  • 📚 4 интерактивных урока Python
  • 📋 Канбан-доска на Flask API
  • ⏱ Pomodoro-таймер на JavaScript
  • 🚀 Готовность к деплою на Render

Технологии

  • Python 3.11 + Flask
  • HTML5, CSS3, Vanilla JS
  • JSON-хранилище (легко заменить на PostgreSQL)

Как задеплоить

Проект готов к Render: файлы Procfile и render.yaml уже включены.
